# Qoneqt ContentForge AI

> **"From Community Ideas to Publish-Ready Stories"**  
> *Built by Team ARCLIGHT for the Qoneqt Hackathon 2026*

---

## 🚀 Overview

**Qoneqt ContentForge AI** is an autonomous AI Creator Studio prototype designed to bridge the gap between unstructured community discussions and viral, high-retention short-form video stories. 

Within 15–20 seconds, the engine deconstructs a topic, mobilizes 8 specialized AI agents, drafts a 5-scene viral arc, synthesizes neural voiceovers, renders kinetic captions, and certifies the package with an engagement quality score (94%+), ready for one-click publishing to the **Qoneqt Global Feed**.

---

## ⚡ Key Features

- **Futuristic AI Creator Studio Interface**: Deep dark theme (`#05020D`), glassmorphism cards, glowing neon purple & cyan borders, subtle particle grid, smooth micro-animations.
- **⚡ Automated Demo Mode**: One-click 15-second guided tour specifically tuned for hackathon judges (Topic Selection → 9-Stage Pipeline → Storyboard & Script → 9:16 Video Preview → Ready to Publish).
- **📽 Hackathon Presentation Mode**: Cinematic full-screen slide flow demonstrating the 5-step mental model:
  $$\text{Community Idea} \rightarrow \text{AI Director} \rightarrow \text{Content Pipeline} \rightarrow \text{Short-Form Video} \rightarrow \text{Qoneqt Feed}$$
- **Interactive 9:16 Phone Reel Preview**:
  - Realistic smartphone bezel with speaker notch, battery & dynamic time.
  - Word-level animated kinetic captions synchronized with live playback.
  - Interactive play/pause, time scrubber, and Web Audio API synthesized ambient audio.
- **Full Content Package**:
  - High-impact opening viral hook.
  - 5-Scene structured narrative (The Question, The Revolution, Dev + AI, Future Skills, Final Message).
  - Verified badges: AI Voice Generated ✓, Auto Captions ✓, 94% Content Quality Score.
- **Production Actions**:
  - **▶ Preview**: Full-screen interactive video player modal with timeline scrubbing.
  - **✏ Edit**: In-place script editor to customize the hook, scenes, and captions.
  - **⬇ Export**: Instant download of formatted JSON content package with complete metadata.
  - **🚀 Publish to Qoneqt**: One-click broadcast with celebratory confetti burst and feed certification.
- **Community Ideas Hub**: Real-time trending debates with discussion counts, sentiment, and `Convert to Content →` buttons.
- **AI Content Director (Multi-Agent Swarm)**: Visual topology map of 8 specialized agents (*Research, Script, Storyboard, Visual, Voice, Editor, QA, Publisher*).
- **Local Persistence**: Preserves generated scripts, published metrics, and stats across refreshes using `localStorage`.

## 🛠 Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + Custom Glassmorphism & Neon Glow Utilities
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **Sound Effects**: Native Browser Web Audio API (Zero external network dependencies)

## 🏁 Quick Start & Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Launch Local Development Server
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 3. Production Build
```bash
npm run build
```
